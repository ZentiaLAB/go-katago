# หมากล้อม vs KataGo (Local AI)

เกมหมากล้อมบนเว็บที่รันทุกอย่างบนเครื่อง (Mac M4 Pro) — ไม่ต้องใช้อินเทอร์เน็ตระหว่างเล่น

## เริ่มเล่น

ต้องมี macOS (Apple Silicon), Homebrew และ Python 3

```bash
./start.command
```

ครั้งแรกจะติดตั้ง KataGo (`brew install katago`) และดาวน์โหลดโมเดล ~370 MB ให้อัตโนมัติ (`scripts/download_models.sh`)

(หรือดับเบิลคลิก `start.command` ใน Finder) แล้วเบราว์เซอร์จะเปิด http://localhost:8765
ครั้งแรก AI จะวอร์มอัพ ~30 วินาที (คอมไพล์โมเดลลง GPU + Neural Engine)

## โหมดการเล่น

เปิดเว็บมาจะเจอหน้า **เกมใหม่** ให้เลือกโหมดก่อน (กดปุ่ม "เกมใหม่" เพื่อเปลี่ยนได้ตลอด ระบบจำค่าที่เลือกล่าสุดไว้):

| โหมด | ตั้งค่าอะไรได้ |
|---|---|
| 🤖 **เล่นกับ AI** | สีของคุณ (ดำ/ขาว/สุ่ม) · AI คู่แข่ง: **ระดับฝีมือ** (เต็มกำลัง / เลียนแบบคน 18k–9d) + **เวลาคิดต่อท่า** (1–30 วิ) · ผู้ช่วยของคุณ: ปิด/เร็ว/มาตรฐาน/ลึก/สุดกำลัง |
| 👥 **P2P · 2 คน** | ผู้เล่น 1 = ดำ, ผู้เล่น 2 = ขาว ผลัดกันเดินบนเครื่องเดียว · **แต่ละคนเลือกระดับผู้ช่วย AI เองหรือปิดได้** (ใช้เป็นแต้มต่อให้มือใหม่) |
| 🌐 **ออนไลน์** | สร้างห้องแล้วส่งลิงก์/รหัส 6 ตัวให้เพื่อน หรือเข้าห้องด้วยรหัส · แชทกับคู่แข่งได้ · เลือกผู้ช่วยของตัวเอง |
| 👀 **AI vs AI** | ตั้งระดับและเวลาคิดของ AI สองฝั่งแยกกัน — มีปุ่ม ⏸ หยุด/▶ เล่นต่อ |

**ปิดผู้ช่วย** = ในตาของผู้เล่นคนนั้นจะไม่เห็นคำแนะนำ, % ชนะ/แต้ม, แผนที่พื้นที่, แท็บเทียบ AI และแชท
(ทุกอย่างกลับมาแสดงหลังจบเกม) · ท่าของคนที่เปิดผู้ช่วยยังถูกรีวิวตามปกติ โดยไม่บอกท่าตอบโต้ให้อีกฝ่าย

## เล่นออนไลน์ (ห้อง)

```bash
./start.command --online
```

- เปิดแบบนี้แล้วเพื่อนที่อยู่ **Wi-Fi เดียวกัน** เข้าได้ทางลิงก์ที่ขึ้นในแถบห้อง (เช่น `http://192.168.1.104:8765/?room=ABC123`)
- ถ้าจะเล่นกับเพื่อน **ข้ามอินเทอร์เน็ต** ใช้หน้าเว็บบน Vercel + tunnel ไปที่ Mac:
  ```bash
  brew install cloudflared      # ครั้งแรกครั้งเดียว
  ./scripts/play-online.sh
  ```
  สคริปต์จะเปิด Cloudflare Quick Tunnel, รันเซิร์ฟเวอร์ แล้วพิมพ์ลิงก์ `https://go.zentia.tech/?server=…` กับรหัสเข้าถึงให้
  (การเปิด tunnel = เครื่องนี้รับคนจากอินเทอร์เน็ตที่มีลิงก์ — กด Ctrl+C ปิดเมื่อเล่นเสร็จ, ลิงก์ tunnel เปลี่ยนทุกครั้งที่เปิดใหม่)
- เซิร์ฟเวอร์เป็นกรรมการ: ตรวจกติกา/ลำดับตาเอง, นับแต้มด้วย KataGo เมื่อผ่านติดกัน
- คนที่เข้าจากเครื่องอื่น (ไม่มีรหัสเข้าถึง) ใช้ได้เฉพาะ API ของห้อง — เรียก KataGo/LLM/ข้อมูลเครื่องโดยตรงไม่ได้,
  ผู้ช่วยของแต่ละคนวิเคราะห์ได้เฉพาะตำแหน่งปัจจุบันของห้องตามระดับที่เลือก
- ห้องเก็บในหน่วยความจำ (หายเมื่อปิดเซิร์ฟเวอร์) และหมดอายุเมื่อไม่มีการเล่น 6 ชม. · รีเฟรชหน้าแล้วกลับเข้าห้องเดิมได้ (จำ token ไว้ในเบราว์เซอร์)
- ห้องที่ผู้เล่นครบแล้ว คนที่เข้ามาเพิ่มจะเป็นผู้ชม

## หน้าเว็บบน Vercel

https://go.zentia.tech — เฉพาะหน้าเว็บ (โฟลเดอร์ `web/`) ไม่มี AI ในตัว; เชื่อมกับ Mac ที่รัน `play-online.sh`
ผ่านพารามิเตอร์ `?server=` (ลิงก์เชิญใส่ให้อัตโนมัติ) หรือปุ่ม ⚙️ เซิร์ฟเวอร์

| คนที่เปิดหน้าเว็บ | ทำอะไรได้ |
|---|---|
| ไม่มีรหัสเข้าถึง | สร้าง/เข้าห้องออนไลน์ (ผู้ช่วยตามระดับที่เลือก) |
| มีรหัสเข้าถึง (`GO_ACCESS_KEY`) | ทุกโหมด: เล่นกับ AI, P2P, AI vs AI, แชท LLM |

เซิร์ฟเวอร์รับคำขอข้ามโดเมนเฉพาะจาก origin ใน `GO_ALLOWED_ORIGINS` เท่านั้น · deploy ใหม่: `npx vercel deploy --prod`

## AI คู่แข่ง

| ส่วน | รายละเอียด |
|---|---|
| Engine | **KataGo 1.18** (Metal backend) — AI หมากล้อม open-source ที่แข็งที่สุด ระดับเหนือมืออาชีพ |
| โมเดลหลัก | `kata1-b28c512nbt` — โมเดลตัวใหญ่ที่สุดของ KataGo (ฝึกจาก self-play หลายพันล้านตา) |
| ฮาร์ดแวร์ | โหมด mux: GPU 2 threads + Apple Neural Engine 2 threads ≈ 250 visits/วินาที |
| ระดับความยาก | “เต็มกำลัง” (เลือกความลึก 300–8000 visits) หรือ “เลียนแบบมนุษย์” 18 คิว – 9 ดั้ง ด้วยโมเดล `b18c384nbt-humanv0` |

> ทำไมไม่เทรนเอง? KataGo ผ่านการเทรนด้วยเครื่องจำนวนมากจากอาสาสมัครทั่วโลกมาหลายปีแล้ว
> ถ้าเทรนบน Mac เครื่องเดียว ต่อให้ใช้เวลาเป็นเดือนก็ยังเก่งไม่เท่า การใช้ network ล่าสุดของ KataGo จึงให้ AI ที่เก่งที่สุดที่เป็นไปได้
> (ได้ทดสอบ network แบบ transformer `tf3` ล่าสุดด้วย แต่บน Metal ช้ากว่า ~6 เท่า จึงเลือกใช้ b28)

## ผู้ช่วย AI

- ใช้ **KataGo โมเดลเดียวกับคู่แข่ง** และคิดลึกเท่ากันเป็นค่าเริ่มต้น จึง “ฉลาดเท่า” AI ที่คุณเล่นด้วย
- **💡 ขอคำแนะนำ (H)**: แสดงท่าที่ดีที่สุด 6 ท่าบนกระดาน (ตัวเลขบน = % ชนะ, ล่าง = แต้ม/แต้มที่เสีย) ชี้เมาส์เพื่อดูลำดับที่ AI อ่านไว้
- **โค้ชอัตโนมัติ**: รีวิวทุกท่าของคุณ (ยอดเยี่ยม/ดี/ไม่แม่นยำ/พลาด/พลาดหนัก) บอกจำนวนแต้มที่เสีย ท่าที่ดีกว่า และ AI จะลงโทษอย่างไร
- **🗺️ พื้นที่**: แผนที่เจ้าของพื้นที่ + หมากตาย
- **แชท**: ถามอะไรก็ได้เป็นภาษาไทย — ถ้ามี Ollama จะใช้ LLM (`gemma4:12b`) เรียบเรียงคำอธิบาย
  โดยป้อนข้อมูลวิเคราะห์ของ KataGo ให้ (LLM ไม่ได้คิดท่าเอง จึงไม่มั่วพิกัด) ถ้าไม่มี Ollama จะตอบด้วยระบบอธิบายในตัว

เปลี่ยน LLM ได้: `GO_LLM_MODEL=qwen3:14b ./start.command`

## กราฟ (แท็บในแผงขวา)

- **📈 เทียบ AI** — โอกาสชนะและแต้มในสายตา AI คู่แข่ง vs ผู้ช่วย, เวลาและความเร็วการคิดต่อท่า,
  อัตราทายท่ากันถูก, และรายการท่าที่แต่ละฝั่งกำลังพิจารณา (ชี้เมาส์ที่ท่าเพื่อดูลำดับบนกระดาน)
- **🖥️ เครื่อง** — CPU / RAM / GPU ย้อนหลัง 5 นาที แยก KataGo กับ LLM พร้อมแถบสีบอกช่วงที่แต่ละ AI กำลังคิด
  (วัดด้วย `top`, `vm_stat`, `ioreg` ของ macOS ไม่ต้องใช้ sudo · Neural Engine วัดไม่ได้)
- ตัวเลขสรุปอยู่มุมขวาบนตลอดเวลา

## โครงสร้าง

```
server.py            Python (stdlib) — รัน KataGo analysis engine + API + proxy ไป Ollama (127.0.0.1 หรือ LAN เมื่อใช้ --online)
rooms.py             ห้องออนไลน์: กติกาฝั่งเซิร์ฟเวอร์, long-poll, แชท, ผู้ช่วยต่อผู้เล่น
engine/analysis.cfg  config KataGo ที่จูนสำหรับ M4 Pro
models/              ไฟล์ network ของ KataGo
web/                 หน้าเว็บ: go.js (กติกา), explain.js (ระบบอธิบายภาษาไทย), charts.js (กราฟ SVG), app.js (เกม/กระดาน/ผู้ช่วย/กราฟ)
```

กติกาจีน (นับพื้นที่), โคมิ 7.5, รองรับ 9×9 / 13×13 / 19×19, หมากต่อ 2–9, ย้อนท่า, บันทึก SGF
