หมายเหตุการวัด
  • AI คู่แข่งและผู้ช่วยใช้ process KataGo ตัวเดียวกัน จึงแยก RAM ของแต่ละฝั่งไม่ได้ — ดูจากแถบสีว่าใครกำลังใช้เครื่องอยู่
  • KataGo ใช้ GPU + Neural Engine เป็นหลัก CPU จึงต่ำ; การใช้ Neural Engine วัดไม่ได้ถ้าไม่มีสิทธิ์ sudo (powermetrics)
  • RAM ทั้งเครื่องนับแบบ Activity Monitor (App + Wired + Compressed) · Mac ใช้หน่วยความจำร่วม (Unified Memory) GPU จึงใช้ RAM ก้อนเดียวกัน
  • RAM ของ LLM จะขึ้นเมื่อโหลดโมเดลครั้งแรก และจะถูกปล่อยหลังไม่ได้ใช้ 30 นาที
